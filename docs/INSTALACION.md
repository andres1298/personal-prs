# Añadir Mis PRs a la pantalla de inicio

Mis PRs seguirá siendo una aplicación web: el icono de la pantalla de inicio abre el mismo sitio y los mismos datos en una ventana sin barra del navegador cuando el teléfono lo permite. Esa apariencia no la convierte en una app nativa de App Store o Google Play, ni en un widget interactivo.

Antes de empezar, abre en tu teléfono el enlace HTTPS de Mis PRs que te hayan compartido. Necesitarás conexión para cargar tus datos y guardar nuevos PRs.

## iPhone: Safari

1. Abre el enlace en **Safari**.
2. Toca el botón **Compartir**. Según la disposición de Safari, puede estar directamente en la barra o dentro del menú de página.
3. Desplázate y elige **Añadir a pantalla de inicio**.
4. Si aparece la opción **Abrir como app web**, actívala.
5. Confirma con **Añadir**.

Busca el icono **PRs** en la pantalla de inicio y ábrelo desde ahí. Si no aparece «Añadir a pantalla de inicio», baja hasta **Editar acciones** en el menú Compartir y agrega esa acción.

## Android: Chrome

1. Abre el enlace en **Chrome**.
2. Toca el menú de **tres puntos (⋮)** junto a la barra de direcciones.
3. Elige **Instalar aplicación**. En algunas versiones de Chrome la opción se llama **Instalar y crear acceso directo** o aparece dentro de **Añadir a pantalla de inicio**.
4. Confirma la instalación y busca el icono **PRs** en la pantalla de inicio o en el listado de aplicaciones.

Si Chrome solo ofrece **crear un acceso directo**, también podrás abrir Mis PRs desde ese icono, pero puede mostrarse la barra del navegador. Para obtener la ventana sin barra, usa **Instalar aplicación** cuando Chrome la ofrezca.

## Si no ves la opción para añadir el icono

- Comprueba que abriste el enlace publicado en Safari (iPhone) o Chrome (Android), no dentro del navegador integrado de otra aplicación.
- Recarga la página y revisa que el enlace empiece por `https://`.
- El icono no descarga tus PRs para uso sin conexión: vuelve a conectarte si los datos no cargan o no se puede guardar un registro.

Referencias: [Apple: convertir un sitio web en app en iPhone](https://support.apple.com/en-gw/guide/iphone/iphea86e5236/ios) y [Google Chrome: usar apps web en Android](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid).
