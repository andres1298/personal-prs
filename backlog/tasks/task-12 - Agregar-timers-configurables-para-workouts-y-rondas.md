## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Durante un workout hace falta medir tiempo y seguir las rondas sin recurrir a otra aplicación. El usuario debe poder configurar el temporizador antes de iniciar y controlar su ejecución durante el entrenamiento.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 El usuario puede configurar al menos cronómetro, cuenta regresiva e intervalos con duración y número de rondas.
- [ ] #2 El timer muestra tiempo transcurrido o restante y ronda actual de forma clara.
- [ ] #3 Se puede iniciar, pausar, reanudar, reiniciar y finalizar sin perder una ronda por cambios de estado inesperados.
- [ ] #4 El cambio de ronda y el fin del workout se indican con una señal visible; las señales son configurables cuando el dispositivo las permite.
<!-- AC:END -->
